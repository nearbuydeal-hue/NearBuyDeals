# NearbyDeals

NearbyDeals helps people discover available products from local shops and
contact those shops directly.

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
